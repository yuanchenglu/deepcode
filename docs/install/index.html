安装

支持 macOS (arm64/x64) 和 Linux (arm64/x64)。

curl -fsSL https://github.com/yuanchenglu/deepcode/releases/latest/download/install.sh | bash

安装后重新打开终端，或运行 source ~/.zshrc（macOS）/ source ~/.profile（Linux）。

配置 API Key

export DEEPSEEK_API_KEY=sk-your-key-here

将此行加入 ~/.zshrc 或 ~/.bashrc 持久化。

首个任务

deepcode

启动后进入交互式终端。尝试：

帮我读取当前目录的 package.json 并解释项目结构

升级

deepcode upgrade

卸载

deepcode uninstall

卸载只删除 ~/.deepcode/，不影响 OpenCode 或其他工具。

与 OpenCode 共存

DeepCode 与 OpenCode 完全隔离：

  • DeepCode 使用 ~/.deepcode/
  • OpenCode 使用 ~/.opencode/
  • 两者可同时安装，互不影响

Alpha 已知限制

  • 仅支持 CLI，不含桌面应用
  • Gateway（飞书/微信）为实验性
  • Subagent/Multi-Agent 未正式承诺
  • Windows 为非阻塞实验制品

故障排查

安装失败？手动检查：

# 验证 curl 和 shasum 是否可用
command -v curl && command -v shasum

# 手动下载安装器
curl -fsSL https://github.com/yuanchenglu/deepcode/releases/latest/download/install.sh -o /tmp/deepcode-install.sh
sh /tmp/deepcode-install.sh
