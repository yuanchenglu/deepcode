## 1. 三个布局方向（步骤 2 要求 2~3 个有实质差异）

### 方向 A：收敛 New 壳 + 常驻 Sidebar（推荐）

```
┌─────────────────────────────────────────────┐
│ Titlebar: [项目] · Agent ● · [设置]          │
├──────────┬──────────────────────────────────┤
│ Sidebar  │ Main                            │
│ Home     │  会话消息流 / diff / 计划        │
│ 会话列表  │  ┌─ 计划面板（可折叠）─┐        │
│ 归档      │  │ Step 1 ▸ Step 2  │        │
│ 目录      │  └──────────────────┘        │
├──────────┴──────────────────────────────────┤
│ 状态栏: 队列 · 错误回执 · 更新              │
└─────────────────────────────────────────────┘
```
- 信息密度：中（2 层导航）
- 学习成本：低（会话列表常驻，用户熟）
- 扩展性：高（子页面 tabs 可扩展）
- 桌面窗口适配：1024 可收 Sidebar，1440+ 常驻

### 方向 B：全屏沉浸会话（Sidebar 折叠默认）

```
┌─────────────────────────────────────────────┐
│ Titlebar: [项目] · Agent ● · [☰] [设置]     │
├─────────────────────────────────────────────┤
│  Main（全宽）                               │
│   消息流（居中窄栏）                        │
│   ┌ 计划面板（右侧抽屉，默认隐藏）──┐      │
│   └─────────────────────────────┘          │
├─────────────────────────────────────────────┤
│ 输入框（底部固定）                          │
└─────────────────────────────────────────────┘
```
- 信息密度：低（聚焦单一任务）
- 学习成本：低（像聊天）
- 扩展性：中（抽屉式，多任务切换弱）
- 桌面适配：1440+ 佳；1024 窄栏可用

### 方向 C：三栏工作台（Sidebar + Main + Inspector）

```
┌─────────────────────────────────────────────┐
│ Titlebar: [项目] · Agent ● · [设置]         │
├──────────┬──────────────┬──────────────────┤
│ Sidebar  │ Main         │ Inspector        │
│ 会话列表  │ 消息流       │ 计划/子 Agent    │
│          │ 输入框       │ 工具调用/证据     │
├──────────┴──────────────┴──────────────────┤
│ 状态栏                                      │
└─────────────────────────────────────────────┘
```
- 信息密度：高（3 栏并行）
- 学习成本：高（多栏认知负担）
- 扩展性：最高（Inspector 承载 Agent 证据/子任务）
- 桌面适配：1728+ 佳；1024 拥挤（Inspector 需收）

## 2. 关键状态线框（以方向 A 为例，F1-F7）

| 线框 | 状态 | 内容 |
|---|---|---|
| F1 | empty/offline | 欢迎页：无项目 + 打开目录按钮；离线时显示提示 |
| F2 | loading/error | 目录索引骨架；失败时错误页 + 重试 |
| F3 | permission | Provider 配置引导（缺 API key） |
| F4 | running/cancel | 计划面板 + 当前步骤高亮 + 取消按钮 |
| F5 | error/recovery | 失败回执 + 重试/回退步骤 |
| F6 | permission-ask | 工具权限确认弹层（对象 + 可恢复性） |
| F7 | empty/loading | diff 无变更提示 / 生成中骨架 |

## 3. viewport 验证计划（步骤 6）

- 1024×700：Sidebar 可收；F4 计划面板折叠
- 1440×900：主目标；全组件展开
- 1728×1117：三栏可用（方向 C）或宽消息流（A/B）
- 最小支持尺寸：待原型测试冻结（草案 1024×700）
