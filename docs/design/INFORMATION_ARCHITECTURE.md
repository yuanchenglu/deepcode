# DeepCode 信息架构（INFORMATION_ARCHITECTURE）

> 日期：2026-08-05
> 状态：DRAFT（S3-02 交付）
> 依据：S3-01 审计（双布局现状、87 组件、页面映射）

## 1. 架构目标

- 收敛双布局：**继承 New 壳**（44 行透传壳的简洁性），补齐其缺失的导航入口、加载反馈、错误边界（S3-01 审计结论 3）
- 以任务掌控为核心：T2/T3 是主路径，设置/Gateway 是次级
- 单层导航优先：避免 Legacy 的 5 层堆叠（rail→项目→工作区→会话→设置）

## 2. 信息架构图（proposed）

```
┌─────────────────────────────────────────────┐
│ Titlebar: 项目名 · 状态 · Agent 指示 · 设置   │
├──────────┬──────────────────────────────────┤
│ Sidebar  │  Main（当前任务）                 │
│ · Home   │  · 会话消息流                     │
│ · 会话列表│  · 计划/子 Agent 面板             │
│ · 归档   │  · diff/review 面板               │
│ · 目录   │  · 权限确认弹层                   │
│          │  · 终端（可折叠）                 │
├──────────┴──────────────────────────────────┤
│ 状态栏: 队列深度 · 错误回执 · 更新提示        │
└─────────────────────────────────────────────┘
```

## 3. 导航层级（对比）

| 层级 | Legacy（现状） | Proposed |
|---|---|---|
| 1 | 64px 图标 rail | 折叠 Sidebar（可收起） |
| 2 | 项目列表 | 会话列表（当前项目） |
| 3 | 工作区树 | 目录（次级，可切换） |
| 4 | 会话列表 | 归档（次级） |
| 5 | 设置齿轮（rail 底部） | Titlebar 右上设置 |

**简化点**：项目/工作区/会话三层合并为"会话列表 + 目录"两层；设置移入 Titlebar。

## 4. 页面 → 任务映射

| 页面 | 任务 | 状态覆盖 |
|---|---|---|
| home | T1 打开项目 | loading（打开中）、empty（无项目）、error（目录失效） |
| new-session | T2 发起任务 | loading（模型就绪）、permission（Provider 配置缺失） |
| session | T2/T3 掌控+审查 | running（计划/工具）、cancel（可取消）、error（失败回执）、recovery（重试/继续） |
| diff/review | T3 审查 | empty（无变更）、loading（diff 生成中） |
| settings | Gateway/多 Agent | offline（连接断开）、error（凭据无效） |
| 权限确认 | 弹层 | ask（待确认）、deny（拒绝记录） |
